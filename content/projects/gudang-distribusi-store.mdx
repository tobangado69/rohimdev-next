Gudang Distribusi Store Builder is the **WhatsApp Online Store Builder** SaaS behind [admin.gudangdistribusi.com](https://admin.gudangdistribusi.com/). It is a separate product from the **Project Forwarder** marketplace at [gudangdistribusi.com](https://gudangdistribusi.com/), which handles WhatsApp project routing between owners and freelancers.

## Platform modules (from public screenshots)

| Module | Purpose |
| --- | --- |
| **Products** | Catalog creation and merchandising |
| **Product view** | Customer-facing product detail experience |
| **Brand settings** | Logos, identity, and store branding |
| **Overview** | Merchant dashboard and operational snapshot |
| **Shipping** | Fulfillment methods and delivery rules |
| **Themes** | Storefront look-and-feel without custom code |

## Subscription capabilities (Free plan reference)

The marketing site advertises plan limits and toggles including:

- **5 users**, **2 stores**, **20 products**, **1024 MB** storage (Free tier example)
- **Custom domain** and **subdomain**
- **Shipping method**, **additional pages**, **blog**
- **Progressive Web App (PWA)**
- **ChatGPT** integration

Pricing is shown in **MYR**, reflecting Malaysia-focused go-to-market.
